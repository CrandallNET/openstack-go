usage: openstack trait create [-h] <name>

Create a new custom trait. Custom traits must begin with the prefix
``CUSTOM_`` and contain only the letters A through Z, the numbers 0 through 9
and the underscore "_" character. This command requires at least ``--os-
placement-api-version 1.6``.

positional arguments:
  <name>      Name of the trait.

options:
  -h, --help  show this help message and exit

This command is provided by the osc-placement plugin.
