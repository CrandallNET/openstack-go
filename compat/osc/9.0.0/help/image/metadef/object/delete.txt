usage: openstack image metadef object delete [-h] <namespace> [<object> ...]

Delete metadata definitions object(s)

positional arguments:
  <namespace>  Metadef namespace of the object (name)
  <object>     Metadef object(s) to delete (name) (omit this argument to
               delete all objects in the namespace)

options:
  -h, --help   show this help message and exit
