usage: openstack resource provider trait delete [-h] <uuid>

Dissociate all the traits from the resource provider. Note that this command
is not atomic if multiple processes are managing traits for the same provider.
This command requires at least ``--os-placement-api-version 1.6``.

positional arguments:
  <uuid>      UUID of the resource provider.

options:
  -h, --help  show this help message and exit

This command is provided by the osc-placement plugin.
